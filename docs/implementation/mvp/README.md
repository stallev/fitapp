# Implementation MVP

Фазовая декомпозиция разработки Pulse — формат идентичен lampto.

## Структура

| Каталог | Содержимое |
|---------|------------|
| `phases_tasks_descriptions/` | `P{N}_phase_description.md` |
| `tasks/` | `P{N}_tasks.md` — чеклисты для агентов |
| `contracts/` | Контракты между модулями |
| `specs/` | Детальные specs (booking wizard, trainer onboarding) |
| `guides/` | Env, deploy, migrations |
